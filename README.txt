Joy Dao Portfolio - Image Assets Instructions
==============================================
Place your photos in this folder with the following filenames:

1. profile.jpg
   - Your profile portrait for the "About Me" storybook section.
   - Recommended size: Square or 4:5 portrait (e.g. 600x750px or 800x800px).

2. mun-main.jpg
   - The primary featured photo for the Model United Nations section.
   - Recommended size: 1200x800px landscape.

3. mun-01.jpg, mun-02.jpg, mun-03.jpg, mun-04.jpg
   - Optional supporting photos from conferences, committee chairing, or team moments.
   - If you don't have all 4 photos yet, don't worry! The website automatically hides any photo slots that haven't been added yet without showing broken image icons.

4. dance-01.jpg and dance-02.jpg
   - Two optional photographs for the Dancing section in Joy’s Little Things.
   - If either file is missing, a styled placeholder remains until you add your image.

5. pond-reference.webp
   - The supplied painting used as the portfolio background in both themes.
Any standard image format (JPG, PNG, WebP) can be used. Simply name them as above!
